Put local static assets here if you want to import them directly in code (e.g. `src/assets/logo.png`).

For now, the app renders a CSS wordmark as the logo (see `src/components/Logo.jsx`) since no logo
file was provided when this project was generated. The admin can also upload a logo image from
`/admin/settings`, which is stored in Supabase Storage rather than this folder — that's the easier
path if you just want your existing AXKN07 Crochet logo to appear.
